# Image prompts for Ember Oak

The new pages currently reuse photos from the homepage, so some appear more
than once across the site. These prompts are for AI-generated replacements.

**How to use them:** generate the image, save it with the file name shown,
and upload it to `public/assets/images/` on GitHub. Then tell Claude which
files you added, and it will switch the pages over to use them.

**Style to add to every prompt** (keeps the set consistent with the existing photos):

> Professional food and restaurant photography, warm moody lighting, deep
> shadows, rich natural colours, shallow depth of field, shot on a full-frame
> camera with a 50mm lens, no text, no logos, no watermarks, photorealistic.
